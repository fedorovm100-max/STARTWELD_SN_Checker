# STARTWELD SN Checker

Автономное Android-приложение для ТСД. Интернет не нужен.

Встроенный список: **400 серийных номеров** `SN260724N500201` ... `SN260724N500600`.

## Работа
- поле сканирования всегда держит фокус;
- Enter не нужен: полный СН принимается сразу, иначе ввод обрабатывается через 250 мс;
- найденный СН удаляется из остатка;
- повторный скан показывает «УЖЕ СКАНИРОВАЛИ»;
- чужой СН показывает «НЕТ В СПИСКЕ»;
- прогресс хранится в SharedPreferences и переживает закрытие приложения;
- можно отменить последнее успешное сканирование;
- можно показать/скопировать остаток;
- можно полностью начать заново.

Совместимость: **Android 4.1+ (API 16)**. Без AndroidX и без сетевых разрешений.

## Сборка в GitHub Actions
После загрузки workflow сборка запускается автоматически. Готовый artifact называется `STARTWELD_SN_Checker_APK`.
